Who uses this app

This app is used only by its operator and the operator's own Google accounts. It is not available to the public.

Data accessed

With the user's consent, the app accesses Gmail data through the Gmail API: reading messages (gmail.readonly) and, for the assistant's own account, sending mail and reading send-as settings.

How data is used

Gmail data is used solely to provide the operator's personal assistant features (for example, summarizing or locating the operator's own email). It is not used for advertising, not sold, and not transferred to any third party except as necessary to provide these features to the operator, and not used to train generalized AI/ML models.

Storage

OAuth tokens are stored encrypted in the operator's password manager. Message content is processed on the operator's own machines and is not retained beyond what the operator's tasks require.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
